## Technical Stack Quick Reference

* **Framework**: Laravel 11/12 (PHP 8.2+)
* **Single Page App Engine**: Inertia.js (React 19 + TypeScript)
* **Design & Styling**: Tailwind CSS v4 + Radix UI Primitives
* **Database**: MySQL / MariaDB (production), SQLite (in-memory test suite)
* **Build System**: Vite 6
