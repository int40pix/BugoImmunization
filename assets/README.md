# Project Assets

This directory houses static media, design references, branding iconography, and submission documents for the capstone project.

## Directory Structure

```
assets/
├── images/       # Brand graphics, health center seals, system banners, and mockups
├── icons/        # Custom SVG icons, vector assets, and app logos
└── documents/     # Capstone documentation briefs, forms, and submission attachments
```

## Production Web Assets Note
In this Laravel + Inertia application, assets served directly by the web server at runtime reside in [`../public/`](../public/) and are compiled through Vite from [`../resources/`](../resources/). The files in this `assets/` directory serve as repository-level sources, design artifacts, and capstone assets.
